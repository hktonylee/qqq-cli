# qqq CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task inline. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver local Rust task CLI with persistent session ownership and Herdr lookup.
**Architecture:** CLI parsing in main.rs, SQLite lifecycle in db.rs, typed Herdr adapter in herdr.rs. Integration tests execute real binary against temporary directories.
**Tech Stack:** Rust, clap, rusqlite bundled SQLite, serde, serde_json, anyhow, tempfile.
