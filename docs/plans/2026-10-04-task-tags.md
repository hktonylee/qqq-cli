# Task Tags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task inline. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Persist tags, show tags before task names, edit via Ctrl-L, move task jump to Ctrl-K.

**Architecture:** Store a JSON tag array on each task with shared Rust normalization. Extend existing transactional DB options and CLI/import paths, reuse the action popup for metadata edits without reloading description drafts.

**Tech Stack:** Rust, Clap, SQLite/rusqlite, Serde, Ratatui/Crossterm, Python PTY harness.

---
