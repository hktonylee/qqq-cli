Routing and key precedence

Source: Event routing, lines 1460–1640 and 1638–2227

mod.rs:1638: agent > view > bulk > jump > conflict > q/Q escape alias for confirmations/menu/error > Ctrl+B opening > local tag cancel > global filter clearing > Ctrl+C ExitBuffers guard > New draft reset > dashboard Escape/Ctrl+C navigation > pending confirmation > Ctrl+H > action UI > direct shortcuts > filter/editor.

  • All mouse events are ignored while any dialog or confirmation is active (mod.rs:1460).
  • Paste routes to the active input; menu/error paste does not edit the draft. Confirmations and conflict ignore paste (mod.rs:1499).
  • q/Q alias Escape in non-text menus, previews, errors, confirmations and conflict; literal text in input fields and editor.
  • Active filter query/focus can consume the first Escape/Ctrl+C while a single-task menu, non-tag input, action error, or completion confirmation remains open. Reopen and mark-error confirmations bypass this filter-clear guard (mod.rs:1910).

Single-task actions

Source: Action UI, lines 142–277, 441–502 and 2001–2482 · Completion callback, lines 715–742 · Recoverable completion errors, lines 1–32

mod.rs:142-277, 441, 2001-2150, 2210-2482; main.rs:715; completion.rs:1-32.

  • Ctrl+G selects the bulk menu whenever any bulk selection exists, even if a single task is focused.
  • Menu Up/Down wraps; Enter activates highlighted item. c=Complete (unless completed), e=Mark error (unless completed/error), r=Retry (error only), o=Reopen (unless error), p=Priority, d=Parent, a=Archive/Unarchive. Menu visibility is not DB validity: New offers Reopen but execution may reject it.
  • r/o/a always go to action confirmation, even with a clean draft. c also confirms after resolving the completion action; an error in that resolution opens Action error directly.
  • p/d open scalar input. Enter validates priority -100..100, or parent ID/none. Validation errors remain inline. Valid input with a clean draft executes directly; a dirty draft goes to confirmation.
  • e opens error reason. Enter requires nonblank reason, then always confirms.
  • Escape closes the menu or priority/parent/error-reason input directly to the editor, dropping entered values. Inputs do not return to the menu. The earlier filter-clear guard can consume the first Escape; q/Q remains literal text in inputs.
  • Confirmation y executes normal action; Y forces Complete, Reopen and Mark error. Other actions y/Y are equivalent. n/N/Enter/Escape cancel. q/Q map to Escape.
  • Completion callback initially labels confirmation Complete when this session owns the selected task, otherwise Force complete (also when identity discovery is unavailable). Even a Force complete-labelled confirmation still maps lowercase y to normal Complete; uppercase Y performs the force.
  • Successful actions reload task state and discard active unsaved changes after confirmation. Archiving with archives hidden moves to general New.
  • A normal Complete failing due to missing identity/dispatch/ownership stays in the same confirmation with error and force option. Other failures, including Force complete, Reopen, Mark error, priority and parent, open the scrollable Action error dialog.
  • Action error Enter/Escape/q/Q closes; Up/k and Down/j scroll. Ctrl+C follows dashboard cancellation before this local handler and can navigate to New or a discard-switch footer for a saved task.
  • Ctrl+C on a saved task during a completion confirmation can replace it with discard-switch or navigate to New; reopen/mark-error confirmations instead retain the prompt on Ctrl+C. ExitBuffers ignores Ctrl+C.

Tags

Source: Tag input dispatch, lines 1910–1920, 2185–2225 and 2485–2530 · Tag editing and autocomplete

mod.rs:1910, 2185-2225, 2485-2530; tag_input.rs.

  • Ctrl+S validates and saves; Enter inserts a line, Tab accepts a project-tag completion, Ctrl+U clears current logical line. Suggestions are part of this dialog, not another popup.
  • On saved task, save writes tags directly while retaining dirty description. On New, save stages tags in the draft; editor Ctrl+S creates the task later.
  • Parsing/write errors remain inline in tags. Escape/Ctrl+C closes locally, retaining description and filter.
  • Failure reading the selected task when opening tags gives Action error. Project-tag catalog load uses ?, so its exceptional failure exits the command rather than displaying a popup.

Jump

Source: Jump dialog · Jump loading, lines 1773–1813 and 2530–2545

jump.rs:30; mod.rs:1773-1813, 2530.

  • Enter requires positive integer and existing task; bad input or failed lookup stays inline.
  • Success parks current draft and loads/restores target draft, enables archive/completed visibility if needed, clears filter and closes dialog.
  • Escape/Ctrl+C closes locally. Ctrl+U clears field. q/Q remains input.

Views

Source: View picker · View form · Templates · View apply/save, lines 1668–1718 and 1886–1910

view_picker.rs:64-134; view_form.rs:53-112; view_templates.rs; mod.rs:1668-1718, 1886.

  • Ctrl+B catalog load failure is footer error, no dialog. Picker Up/Down/Home/End selects, PageUp/PageDown scrolls script preview; Escape/q/Q/Ctrl+C closes.
  • Picker Enter validates/applies view or All tasks, then closes; apply failure stays inline in picker.
  • n opens Name + Luau script form. Tab/BackTab toggles fields; Enter in Name moves to Script, Enter in Script inserts newline.
  • Ctrl+S validates and writes catalog. Invalid definition/write failure stays inline in form. Success returns to picker selecting the new entry; it does not apply the view.
  • Ctrl+F from form opens Templates. Enter copies selected template into editable script and returns to form. Escape/q/Q/Ctrl+C returns to form without replacing text.
  • Form Escape/Ctrl+C returns to picker, retaining catalog. q/Q remains text in form.

Bulk

Source: Bulk stages and key handling, lines 139–359 · Bulk dispatch, lines 1720–1772 and 2581–2642

bulk.rs:139-359; mod.rs:1720-1772, 2581-2642.

  • Ctrl+D on saved task toggles selection directly. On New it opens range selector over visible IDs.
  • Range Enter parses one ID or inclusive range, intersects visible IDs and extends selection. Invalid/no matching IDs stay inline. Success closes to editor; Ctrl+G is a separate step. Escape/Ctrl+C cancels without clearing existing selection.
  • Bulk menu t=Add tags, s=Replace tags, p=Priority, r=Remove tags, a=Archive, u=Unarchive, x=Clear selection and close.
  • Add/replace tags Ctrl+S parses and requests preview; Enter inserts newline. Priority Enter or Ctrl+S validates and previews. Validation errors remain inline.
  • Remove tags loads union of selected tasks' tags. Space toggles a label; Enter/Ctrl+S previews when at least one checked. Empty/no checked stays inline. Load failure opens Bulk error.
  • Archive/unarchive requests preview immediately.
  • Preview y/Y applies captured report; successful application closes and clears selection. Apply conflict/failure opens Bulk error and retains selection. Preview building failure also opens Bulk error.
  • Preview n/N/Enter/Escape/q/Q/Ctrl+C closes without applying. Error Enter/n/N/Escape/q/Q/Ctrl+C closes. Inputs/checklist Escape/Ctrl+C close whole wizard, not return to menu. Selection survives all these cancellations and failures; reopen Ctrl+G for a fresh preview.
  • Bulk changes preserve active and parked description drafts. Project-tag catalog load before bulk menu uses ?, so its exceptional failure exits the command.

Content conflict

Source: Comparison and nested confirmations, lines 66–176 · Resolution and save, lines 1815–1876 and 2790–2865

conflict.rs:66-176; mod.rs:1815-1876, 2790.

  • Editor Ctrl+S content conflict opens comparison; other save errors stay in footer. Compare DB/local via Tab/BackTab and scroll keys.
  • Escape/q/Q/Ctrl+C closes, keeping local draft.
  • r/R and o/O open separate reload/overwrite confirmations only while current task exists. Removed task comparison offers only Keep.
  • Nested n/N/Enter/Escape/q/Q returns to comparison. Nested Ctrl+C closes entire conflict and keeps local.
  • Reload y/Y reads newest DB text, discards local text/pending images and closes. Reload failure returns to comparison plus footer error; deleted task removes reload/overwrite options.
  • Overwrite y/Y retries save against captured revision. Success closes; another race opens a new comparison; other failure closes modal with footer error, local draft retained.

Herdr

Source: Editable prompt · Startup, prompt and attach, lines 71–213 · Herdr dispatch, lines 1638–1668 and 2150–2185

agent_create.rs:41-65; handoff.rs:71-213; mod.rs:1638-1668, 2150-2185.

  • Ctrl+H on a saved New task with no Action UI open shows the editable initial prompt even if a Herdr link already exists. Config/project-root error stays in footer. Other saved statuses focus existing linked pane and attach directly; absent link/failed focus is footer error. No selected task gives footer error.
  • Ctrl+H runs before the single-task Action UI handler. From its menu, scalar input, tags input, or Action error, it attempts to focus/attach the existing linked agent and retains the open popup on return. This also bypasses the create-prompt route for a saved New task. Other modal families and confirmations consume this key first.
  • Prompt Enter inserts newline, Ctrl+H submits nonblank text; blank stays inline. Ctrl+S does not submit. Escape/Ctrl+C closes locally.
  • Submission leaves TUI terminal, creates project tab/workspace pane, waits at most 10 seconds for detected Codex idle/done, atomically associates eligible New/unclaimed task, invokes herdr agent prompt once, focuses tab and attaches Herdr. Pane shell startup supplies Codex.
  • Blocked/timeout/identity/claim/prompt/focus/attach errors return to editor footer, not Action error. Already-created pane remains for inspection; prompt uncertainty warning says inspect before retrying. Returning from Herdr restores TUI with footer result.

Exit and discard

Source: Exit states and cancellation, lines 90–139, 1146–1160, 1910–2150 and 2866–2935

mod.rs:90-139, 1146-1160, 1910-2150, 2930.

  • Filter query/focus clears before dashboard Escape/Ctrl+C navigation except local-cancel dialogs and passive reopen/error confirmations.
  • Escape from saved task or nonempty/child New: a dirty draft opens footer-only Switch confirmation; a clean draft loads general New (restoring a parked New draft if present).
  • Dirty means changed text, nonempty staged tags, or pending image atoms (draft.rs, lines 608–614). Tags-only New drafts therefore take the discard-switch route too.
  • Escape from blank general New exits directly if no parked dirty buffers. Otherwise ExitBuffers shows one modal per parked dirty draft with preview. y/Y advances; after last exits. n/N/Enter/Escape/q/Q cancels exit; all retained buffers survive even previously approved ones. If current inspected buffer's DB task was removed, cancel restores that retained draft into editor.
  • Ctrl+C on nonempty New with no action/confirmation clears current New draft immediately, preserving other parked drafts. Ctrl+C on empty New (including an empty child draft) checks parked buffers and exits, unlike Escape on an empty child which returns to general New. Ctrl+C on saved task navigates to general New or opens dirty Switch confirmation.
  • Switch y/Y loads destination; n/N/Enter/Escape/q/Q cancels. Ctrl+C on saved target can recreate Switch via earlier dashboard logic; otherwise pending confirmation retains it.
  • Shared Confirmation::Exit is a footer-only non-dashboard add/edit path: Escape on nonempty draft -> Discard draft?; y/Y exits (after buffer checks), n/N/Enter/Escape/q/Q cancels. It is not a distinct dashboard popup entry.

Review hotspots to display as behavior, not claimed fixes

Source: Existing PTY regression scenarios (not run for this documentation draft)

  • Enter applies values but cancels confirmation dialogs; Y means force only for selected single-task actions.
  • Some first Escape/Ctrl+C events clear filter rather than close Action UI.
  • Ctrl+C closes most local dialogs but navigates from saved task Action UI, retains passive confirmations, and ignores ExitBuffers.
  • Bulk cancellation closes wizard and retains selection; creating view returns to picker without applying it.
  • New draft Ctrl+C discards current draft without confirmation; Escape uses a discard-switch footer.
  • Complete's normal owner/dispatch error can recover in place via Y; reopen/error failures open Action error instead.
  • Force-complete-labelled dialog still requires uppercase Y for force.
