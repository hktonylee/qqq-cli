# Task TUI click selection and editor caret

`qqq tui` already captures mouse input for wheel scrolling. A single left-button press on a visible task row selects that row's task and loads its complete description into the lower editor. The click resolves against the exact `panel::ListRow` slice and `list_top` offset used for the last draw, so tree indentation, description continuation rows, active filter, and manual wheel scroll map to the displayed task ID. Clicking the currently selected task only focuses the editor; it does not discard or reload a dirty draft.

The same Ratatui pane split defines click geometry. List heading, filter bar, ID header, separator, rows below the rendered list, editor heading/footer, undersized terminal, and coordinates outside the terminal have no click action. A click in a visible editor content row focuses the editor and places the caret at the nearest grapheme boundary to the clicked column; clicking past text on that row selects line end. Editor body rows beyond content do nothing. The editor's current scroll offset maps screen row to layout row. Mouse movement, other buttons, and inactive clicks are consumed inside the input-read loop without a DB query or redraw.

Task loading reuses existing `Target`/`Draft::from_saved` flow. A dirty draft for a different clicked task opens the existing discard confirmation. Rejecting confirmation retains draft, selection, and filter focus; accepting loads the target and focuses editor. Load errors appear in the existing error footer while preserving current draft. Ctrl-S keeps current update/new-task behavior. Clicking editor never changes text or saves.

Pure hit-test tests cover task rows, continuation rows, scroll/filter row offsets, editor coordinates, and inactive regions. PTY tests send Xterm SGR left-click reports to verify row selection, wrapped and indented tasks, filter plus wheel scroll, dirty confirmation, editor caret placement, save, no-op clicks, and DB preservation. Existing wheel, keyboard, resize, and terminal restoration tests remain passing.
